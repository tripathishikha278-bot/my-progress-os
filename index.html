MENTOR'S GUIDANCE

What to prioritise over the next 8 weeks

  1. Weeks 1–2: Python variables, conditions, loops, and daily exercises; begin DSA with Big-O and arrays.
  2. Weeks 3–4: Python strings, lists, dictionaries, and functions; practise array and string problems.
  3. Weeks 5–6: Python files, exceptions, modules; learn searching and basic sorting.
  4. Weeks 7–8: revise weak topics, solve beginner problems, tidy GitHub repositories, and finish a small project milestone.

Adjust this plan to your syllabus and exam dates. If college gets busy, keep Python/DSA sessions shorter rather than dropping sleep.
