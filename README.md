# My Progress OS

A beginner-friendly personal productivity and learning dashboard for a first-year B.Tech CSE (AI & ML) student.

## Features
- Daily and weekly task tracking
- Weekly schedule template
- Python, DSA, developer tools, and college learning roadmap
- Project tracker with progress sliders
- Focus timer that logs completed sessions
- GitHub, LeetCode, LinkedIn and VS Code quick links
- Weekly progress summary and reflection prompts
- Daily journal
- Local browser storage so tasks and notes remain after reload

## Run it
1. Extract this folder.
2. Open `index.html` in a browser, or open the folder in VS Code and use the Live Server extension.
3. Start adding tasks and ticking roadmap topics.

No build step or package installation is required.

## Important
Data is saved with `localStorage` in the current browser on the current device. It does not sync between browsers/devices and is not a cloud backup. Clearing browser site data can erase it, so export/backup functionality could be a useful future feature.
